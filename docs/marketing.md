# 获客文案

只发给同行。不要写能续上、不要写包过。

## 微信群

做房抵和个贷包的同行，两个小工具在小范围试用，不发未核实的成交价。

1. 银登个人不良转让：先看公开标题和原文链接，PDF 里的未偿本息用脚本抽，抽不到就不报数字。
2. 续贷测算：填估值、剩余本金、房龄，按保守口径或几家广州常用行的经验抵押率，算出缺口。用来跟客户对齐预期，不是银行批复。

免费就能算一版保守口径。银行模板和导出是付费档。要试用直接回我。

## 视频号口播（约 40 秒）

房抵续不上，多数不是客户突然没钱，是估值下来了，抵押率盖不住剩余本金。
我给同行做了个底稿：输入现在估值、剩余本金、房龄，先按保守口径看差多少万，再换广州几家常用行的经验模板对比。
不承诺能续。需要的同行，评论区留「测算」。

## 图文笔记

标题：估值掉了之后，续贷先算缺口，别先答应客户

正文：
这半年问续贷的人还在，但能全额续的少了。客户只听得见「能不能续」，你得先有一张底稿。

我现在固定看三件事：
- 当前估值，而不是当初评估
- 剩余本金能不能被抵押率盖住
- 到期时房龄和借款人年龄超不超

工具按这个顺序出数，并写一句能直接发客户的话，明确写了「不是批复」。

适合自己也在做房抵、不良的同行，不适合拿去对客户打包票。
