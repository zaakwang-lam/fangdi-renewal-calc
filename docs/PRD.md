# 产品需求文档 (PRD) - 房抵续贷可行性计算器

## 1. 背景与目标
房抵经营贷续贷审核越来越严，价值重估下调、政策变化快。目标：为同行提供快速计算工具，辅助客户咨询。

## 2. 目标用户
房抵代理同行、中介人员。

## 3. 核心功能点
- 基础计算：输入房产信息、原贷款、当前预估价值、房龄等
- 输出：大致可续比例、最大额度、风险等级、建议
- 多银行政策模板（房龄上限、抵押率、征信要求等，付费）
- 结果保存与分享
- 历史计算记录（付费）

## 4. 页面流程
1. 首页（计算器）：表单输入
2. 结果页：展示计算结果与解释
3. 模板库：选择银行政策（付费解锁）
4. 我的：订阅管理、历史记录

## 5. 输入字段
- 房产类型（住宅/商铺）、房龄、区域
- 原评估价、当前预估价
- 原贷款金额、剩余年限
- 借款人征信概况、流水情况（可选）

## 6. 计算逻辑骨架
- 基础：可贷额度 = 当前估估 × 抵押率（按房龄/类型调整）
- 可续比例 = 可贷额度 / 原贷款
- 风险提示：价值下降超过X%、房龄超限等
- 模板：预设广州主流银行参数（可更新）

## 7. 变现方式
- 免费：基础计算
- 付费：银行模板库、高级风险分析、历史记录、导出（29/69元/月）
- 虚拟支付 + 赞赏

## 8. 非功能需求
- 计算速度快
- 参数可配置（方便更新政策）
- 结果可分享给客户
