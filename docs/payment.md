# 订阅支付

先用对公或视频号收到第一笔，再接小程序虚拟支付。

## 档位

| 档 | 价格 | 解锁 |
| --- | --- | --- |
| 免费 | 0 | 保守通用口径 |
| 提醒 | 29 元/月 | 保存筛选（与银登工具配套） |
| 专业 | 69 元/月 | 五家银行经验模板、话术复制 |
| 全功能 | 99 元/月 | 专业 + 本地测算记录 |

道具 ID 见 `utils/pay.js`。金额单位是分。

## 接入顺序

1. 个人主体不能开虚拟支付。用企业主体小程序。类目按工具或资讯申报，金融类目审核更严。
2. mp 后台开通虚拟支付，把月卡配成道具。
3. 服务端用 session_key 算用户态签名，用虚拟支付 appKey 算 pay_sig。签名不进小程序包。
4. 前端拿服务端原样的 signData 调 `wx.requestVirtualPayment`。骨架里道具直购 mode 为 `short_series_goods`，上线前对一次微信最新文档。
5. 是否到账以服务端通知为准，再给 openid 记到期日。
6. iOS 虚拟商品限制会变。先保安卓。不行就改对公，不要引导绕过苹果。

话术里保留「不是银行批复」。不要卖保续。
